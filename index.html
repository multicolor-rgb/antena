    01Funkcje

    Wszystko, co potrzebne.
    Nic, co przeszkadza.

    Antena nie próbuje być platformą. Jest radiem: włączasz, wybierasz stację, słuchasz.

    252 stacje, 30 gatunków

    78 polskich (RMF i wszystkie jego kanały, Zet, Chilli Zet, Eska, Antyradio, Radio 357, Radio Nowy Świat, Radio Kampus, TOK FM, Wnet, Polskie Radio, stacje lokalne) oraz zagraniczne — Radio Paradise, FIP, Deutschlandfunk, NTS, Radio Swiss Pop, Venice Classic i osiem kanałów SomaFM.

    baza: 30 KB, generowana z Radio-Browser i przetestowana

    Szukaj i filtruj bez opóźnień

    Wyszukiwanie po nazwie, gatunku i kraju oraz chipsy gatunków. Lista jest budowana raz — filtrowanie to tylko przełączanie klasy CSS, więc nic się nie przerenderowuje.

    content-visibility: auto

    Ulubione

    Gwiazdka klikiem albo klawiszem f. Lista zapamiętana lokalnie, bez logowania i chmury.

    Tytuł grającego utworu

    Metadane ICY/Icecast w pasku u góry, jedno krótkie zapytanie co 15 s. Bez pollowania w tle.

    Klawisze multimediów

    Media Session API — gdy WebKitGTK eksponuje MPRIS, stacja pojawia się też w panelu systemowym.

    Pamięta wszystko

    Głośność, wyciszenie i ostatnia stacja wracają po ponownym uruchomieniu.

    Zero frameworków

    ~34 KB plików interfejsu, brak npm, brak bundlera, brak dev-serwera. UI jest wkompilowane w binarkę.

    HTML + CSS + JS

    Świadomie bez animacji

    Animowany korektor wymuszał w WebKitGTK ciągłe odświeżanie okna. Wskaźnik jest statyczny — i dlatego radio zjada ~4% rdzenia.

    Prywatność domyślnie

    Brak kont, brak telemetrii. CSP blokuje wszystko poza własnymi plikami i strumieniami audio, a uprawnienia Tauri są ograniczone do core:default.

    default-src 'self'

    Własna stacja w jednej linii

    Dopisz wpis do tablicy w ui/stations.js — nowy gatunek automatycznie pojawi się jako chip. Stream padł? Nazwa robi się czerwona, a status pokazuje komunikat błędu.

    { n, u, g, k, b, c }

    02Interfejs

    Ciemny, kompaktowy,
    przyjemnie szybki.

    Okno 440×680 px, jeden element <audio> na całe radio i cztery sekcje, które ogarniasz w pięć sekund.

    • Play, wyszukiwanie, chipsy, lista

      Nic więcej nie trzeba — i nic więcej nie ma.

    • Statyczny wskaźnik „gra”

      Celowa decyzja: brak animacji oznacza brak ciągłego odświeżania okna.

    • preload="none"

      Przed kliknięciem nic się nie łączy z internetem. Zero ruchu w tle.

    • Struktura projektu, którą przejrzysz w minutę

      ui/ to frontend, src-tauri/ to okno i odczyt metadanych ICY w Ruście.

    03Platformy

    Windows i Linux.
    Ta sama binarka z Rust.

    Cele bundli są zdefiniowane w tauri.conf.json, więc na każdym systemie powstaje dokładnie to, co trzeba: na Linuksie .deb i AppImage, na Windowsie instalator .exe (NSIS).

    Windows 10 / 11

    Instalator NSIS — standardowy, cichy kreator. Bez zależności do doinstalowania.

    • Jeden plik .exe, instalacja kilku klików
    • WebView2 zamiast WebKitGTK — lżejszy start
    • Buildy tworzone automatycznie w GitHub Actions
    Antena_1.0.0_x64-setup.exe
    Pobierz instalator .exe

    SmartScreen może pokazać ostrzeżenie o nieznanym wydawcy — wybierz Więcej informacji → Uruchom mimo to.

    Linux

    Natywna paczka .deb dla Debiana/Ubuntu/Minta albo przenośny AppImage, który uruchomisz z pendrive'a.

    • GTK3 + WebKitGTK 4.1, dźwięk przez GStreamer
    • Arch i Fedora — jedna komenda w menedżerze pakietów
    • Możesz też po prostu ./run.sh ze źródeł
    Antena_1.0.0_amd64.debAntena_1.0.0_amd64.AppImage
    Pobierz dla Linuksa

    macOS? Da się — targets w tauri.conf.json zawiera dmg, a workflow trzeba zbudować na maszynie Apple.

    04Instalacja

    Trzy komendy i gra muzę.

    Wybierz swój system. Wszystkie pliki pochodzą z wydania v1.0.0 na GitHubie.

    Windows 10 / 11

    Pobierz instalator NSIS z sekcji Assets i uruchom go podwójnym klikiem.

    1

    Wejdź na Releases → v1.0.0 i pobierz Antena_1.0.0_x64-setup.exe.

    2

    Uruchom instalator. Windows może zapytać o SmartScreen — Więcej informacji → Uruchom mimo to.

    3

    Gotowe. Antena pojawi się w menu Start; ustawienia (głośność, ostatnia stacja) zapisują się lokalnie.

    Pobierz .exe

    Debian / Ubuntu / Mint — paczka .deb

    Paczka deklaruje zależności libwebkit2gtk-4.1-0 i libgtk-3-0, więc apt dociągnie je sam.

    # pobierz plik z Releases, potem:
sudo apt install ./Antena_1.0.0_amd64.deb
    # alternatywnie, gdy wolisz dpkg
sudo dpkg -i Antena_1.0.0_amd64.deb && sudo apt -f install
    Pobierz .deb

    AppImage — bez instalacji

    Jeden plik, który działa wszędzie tam, gdzie jest WebKitGTK 4.1 i GStreamer. Świetny na pendrive.

    chmod +x Antena_1.0.0_amd64.AppImage
./Antena_1.0.0_amd64.AppImage

    Brak dźwięku? To prawie zawsze brakujące wtyczki GStreamera — zobacz zakładkę Zależności.

    Pobierz AppImage

    Zależności systemowe (Linux)

    Bez kodeków GStreamera radio się uruchomi, ale nie zagra — mp3/mpg123 i aac/faad są w paczkach ugly i bad.

    # Debian / Ubuntu / Mint
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libssl-dev \
  gstreamer1.0-plugins-base gstreamer1.0-plugins-good \
  gstreamer1.0-plugins-ugly gstreamer1.0-plugins-bad gstreamer1.0-libav
    # Arch
sudo pacman -S webkit2gtk-4.1 gtk3 openssl gst-plugins-base \
  gst-plugins-good gst-plugins-ugly gst-plugins-bad gst-libav
    # Fedora
sudo dnf install webkit2gtk4.1-devel gtk3-devel openssl-devel \
  gstreamer1-plugins-{base,good,bad-free,ugly-free} gstreamer1-libav

    Ze źródeł (Rust 1.77+)

    Bez node_modules i bez dev-serwera: pliki interfejsu są wkompilowane w binarkę.

    git clone https://github.com/multicolor-rgb/antena.git
cd antena
./run.sh            # tryb deweloperski (cargo run)
    ./build.sh          # binarka release: src-tauri/target/release/antena
./build.sh bundle   # paczki .deb / AppImage (pobierze tauri-cli, gdy brak)
    # testy parsera metadanych ICY
cargo test --manifest-path src-tauri/Cargo.toml

    07FAQ

    Uczciwe pytania, uczciwe odpowiedzi.

    Dlaczego nie ma Polskiego Radia Trójki ani stacji HLS?
    Odtwarzanie robi WebKitGTK przez GStreamer, a strumienie HLS (.m3u8) nie działają w tym stosie. Antena wybiera więc tylko strumienie progresywne: MP3, AAC/AAC+ oraz OGG/Opus. Dlatego nie ma np. Trójki, która nadaje wyłącznie w HLS.
    Dlaczego proces zajmuje ~0,4 GB RAM?
    To charakterystyka WebKitGTK, nie samej Anteny. Każda aplikacja Tauri na Linuksie używa systemowej przeglądarki i dzieli z nią biblioteki (proces główny ~134 MB, proces strony ~229 MB, sieciowy ~65 MB). Sama binarka Anteny ma 3,3 MB.
    Stacja nie gra i nazwa zrobiła się czerwona. Co dalej?
    Adresy strumieni zmieniają się z czasem i część z nich po prostu umiera. Antena pokazuje to od razu: nazwa robi się czerwona, a w pasku dolnym pojawia się komunikat błędu. Wybierz inną stację albo dopisz własny, świeży adres w ui/stations.js.
    Jak dodać własną stację?
    Otwórz ui/stations.js i dopisz wpis na końcu tablicy: { n: "Nazwa", u: "https://adres/strumienia.mp3", g: "Rock", k: "MP3", b: 128, c: "PL" }. Nowy gatunek automatycznie pojawi się jako chip. Po zmianach w ui/ wystarczy ponownie uruchomić ./run.sh.
    Czy muszę coś instalować razem z aplikacją?
    Na Windowsie nie — instalator NSIS wystarczy. Na Linuksie paczka .deb dociągnie GTK3 i WebKitGTK 4.1, ale kodeki GStreamera (mp3/mpg123 oraz aac/faad) warto mieć zainstalowane, bo bez nich dźwięk nie zagra. Komendy znajdziesz w zakładce „Zależności”.
    Będzie wersja na macOS?
    Cele bundli w tauri.conf.json zawierają już dmg. macOS trzeba jednak zbudować na macOS — Apple nie udostępnia swojego toolchainu na Linuksa. Wystarczy dopisać jedną pozycję do macierzy w .github/workflows/build.yml; komentarz w pliku pokazuje jak.
    Czy aplikacja zbiera jakieś dane?
    Nie. Brak kont, brak telemetrii, brak synchronizacji. CSP blokuje wszystko poza własnymi plikami i strumieniami audio, a uprawnienia Tauri są ograniczone do core:default. Ulubione i głośność siedzą lokalnie na Twoim dysku.
